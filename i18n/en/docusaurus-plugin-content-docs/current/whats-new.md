# What's new

## V1.2.1 (2026-06-01)

**Added**

- OHP flashing. OHP is not intended for RDK ecosystem users, so this manual does not cover OHP flashing.

## V1.2.0 (2026-04-09)

**Added**

- RDK X5 flashing, including full-image flashing, region flashing, and batch flashing.

## V1.1.10 (2026-03-23)

**Added**

- Batch flashing (RDK S100 / RDK S600).
- Partition-image flashing (RDK S100 / RDK S600).

## V1.1.9 (2026-02-02)

First release to replace D-Navigation as the recommended flashing tool for the RDK series. Starting from RDK S100 V4.0.5 and RDK S600 V5.1.0 firmware, XBurn is officially recommended.

**Added**

- Region flashing (RDK S100 / RDK S600).
- Region backup (RDK S100 / RDK S600).
- Batch flashing (X5 chip).
