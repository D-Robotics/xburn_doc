# 连接类型与下载模式

XBurn 烧录需先选**连接类型**（设备与 PC 通信方式），连接类型决定可用的**下载模式**，再进对应模式执行烧录。本篇讲清连接类型、下载模式的选型，以及两者的联动关系。

## 连接类型

XBurn 界面的 **连接类型** 字段选择设备与 PC 通信的方式，实际烧录涉及两种：

| 连接类型 | 说明 | 适用 |
| -------- | ---- | ---- |
| `USB` | XBurn 与设备通信、下发烧录命令的主通道 | S100 / S600（单 Type-C 复用） |
| `Serial+USB` | 串口 + USB 组合：串口经 XModem 引导、USB 经 Fastboot 下发 | X5 / X5 Module（两根线） |

> 串口不单独使用，仅用于日志与 XModem 引导，需与 USB 组合。各型号该选哪种连接、怎么接线，见各产品烧录文档。

## 下载模式选型

按设备当前状态查推荐模式：

| 设备状态 | 推荐下载模式 | 说明 |
| -------- | ------------ | ---- |
| 非空板，正常更新系统 | `Fastboot` | 常用，速度最快 |
| 空板（首次烧录）或系统损坏、变砖 | `DFU+Fastboot` | 需拨码使设备进入 DFU 引导模式；变砖时为无法进入 U-Boot 的恢复路径 |
| 无 DFU 模式的设备 | `XModem+Fastboot` | 经串口 XModem 引导后进 Fastboot |

## 连接类型 → 可用下载模式

连接类型决定可用的下载模式。根据所选连接类型，XBurn 自动匹配可用下载模式：

| 连接类型 | 可用下载模式 | 前置要求 |
| -------- | ------------ | -------- |
| `Serial+USB` | `xmodem_fastboot` / `fastboot` | 串口经 XModem 引导、USB 经 Fastboot 下发；空板或非空板均可 |
| `USB` | `fastboot` | 要求设备 U-Boot 正常并手动进入 Fastboot，操作见各产品烧录文档 |
