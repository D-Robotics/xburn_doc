# 烧录完成自动重启与启动检查

XBurn 在 **设置 → 高级配置** 中提供两项设置：**烧录完成自动重启** 与 **检查设备是否启动成功**，各自独立勾选。

## 烧录完成自动重启

- **开启时**：烧录完成后，XBurn 通过 fastboot 命令让设备重启，进入正常启动模式
- **关闭时**：烧录完成后设备停留在烧录模式，需手动断电、拨回正常启动模式后重新上电

### 建议开启的场景

单台全镜像烧录时建议开启——可一步到位完成"烧录→启动"，无需手动操作开关。

### 建议关闭的场景

**批量烧录**：因为某台烧录完成会立即重启，可能影响其他正在烧录设备的 USB 总线稳定性，也容易混淆"哪台烧完、哪台还在烧"。关闭后所有设备统一烧完，再统一断电重启。



## 检查设备是否启动成功

开启 **烧录完成后自动重启** 后，会出现 **检查设备是否启动成功** 选项，勾选后可检查设备是否进入正常启动状态，省去手动上电与查看启动结果的步骤。

:::info 检查启动成功依赖板端 adb 设备
该检查依赖 adb 设备——若设备系统启动后未生成 adb 设备（如启动卡住），或在板端主动禁用了 adbd，检查会失效。
:::
