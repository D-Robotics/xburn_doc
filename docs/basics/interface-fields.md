# 界面与字段说明

打开 XBurn 后，在主界面配置参数完成烧录任务。本篇给出界面字段的整体清单与各自职责；其中连接类型、下载模式有专门的展开页，本篇只点明其在界面中的位置与作用，不重复细节。

:::info 字段值的型号差异
本篇讲的是字段"含义"（跨型号通用）。每个字段该填什么"值"（如产品类型选 `RDK S100` 还是 `RDK S600`、介质选 `eMMC` 还是 `UFS`），见各产品烧录文档。
:::

## 界面字段总览

XBurn 主界面的核心字段如下：

| 字段 | 作用 | 选错后果 |
| ---- | ---- | -------- |
| 产品类型 | 选择要烧录的设备对应产品类型 | 刷入与设备不兼容的固件，烧录失败 |
| 连接类型 | 设备与 PC 通信的方式 | 影响可用下载模式，选错无法识别设备 |
| 下载模式 | 烧录使用的引导模式 | 模式与设备状态不匹配会无法开始烧录 |
| 存储介质 | 镜像写入的存储介质类型 | 写错介质，无法完成烧录 |
| 固件类型 | 固件的安全类型 | 选错导致烧录失败 |
| 镜像文件目录 | 镜像所在的 product 文件夹 | 目录选错，找不到镜像文件 |
| 高级配置 | 指定区域烧录/备份等进阶选项 | 按需勾选 |

## 产品类型

选择要烧录设备的型号（例如 `RDK S100`、`RDK S600`），它决定可选的连接类型等后续字段。

:::warning 务必与实际型号一致
选与设备实际型号一致的选项，否则会刷入不兼容固件导致烧录失败。
:::

## 连接类型

选择设备与 PC 通信的方式，可选 `USB` 或 `Serial+USB`。产品类型决定可选的连接类型，连接类型再决定可用的下载模式。

连接类型的说明、组合规则与可用下载模式，见 [连接类型与下载模式](./download-modes)。

## 下载模式

XBurn 根据所选连接类型自动匹配可用的下载模式。各型号可用的模式与选型，见 [连接类型与下载模式](./download-modes)。

## 存储介质

选择镜像写入的存储介质类型，与目标存储一致：板载存储（`eMMC`、`UFS`、`NAND Flash`）或 M.2 扩的 NVMe。各型号的介质类型见各产品烧录文档。

## 固件类型

选择固件的安全类型。当前全型号均为 `secure`，默认且唯一可选。

## 镜像文件目录

选择要烧录的镜像文件所在的目录，即解压镜像包得到的镜像文件夹。

## 高级配置

支持如下功能：

- **烧录指定区域**：镜像只写入指定区域。
- **备份指定区域**：导出设备当前某个区域的镜像到 PC。
- **烧录指定分区镜像**：镜像只写入某个分区，粒度比烧录指定区域更细。
- **烧录完成自动重启**：烧录完成后设备自动重启进入正常启动模式，免手动断电拨码。
- **检查设备是否启动成功**：重启后自动检查设备是否正常启动，免手动上电查看。

前三项（烧录指定区域、备份指定区域、烧录指定分区镜像）互斥，一次只选其一；后两项可与前三项组合。详见 [批量烧录](./batch-burn) 与 [烧录完成自动重启与启动检查](./auto-reboot)。
