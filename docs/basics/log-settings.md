# 日志配置

XBurn 的日志级别控制输出日志的详细程度，在 **设置** 页配置。

## 日志级别

| 级别 | 输出内容 | 适用场景 |
| ---- | -------- | -------- |
| `info` | 常规运行信息 | 关注烧录过程细节 |
| `debug` | 详细调试信息 | 烧录失败且常规信息不足以定位原因时，<br />调至 `debug` 并重新复现问题，使日志记录到定位所需的详细内容 |

## 日志位置

日志在两处可见，内容一致：

- **升级进度页**：单击 **开始升级** 后，升级进度页会实时显示烧录日志，用于判断失败环节。
- **日志文件**：日志实时写入 XBurn 安装目录下的 `logs` 文件夹，提交问题反馈时一并附上。
