# 批量烧录

XBurn 支持同时连接多台设备进行批量烧录，适用于产线、批量烧录场景。但多设备并发对 USB 供电、带宽、线材质量均有要求，**并发设备数越多，失败概率越高**。软件只能控制烧录流程本身，无法保证客户的硬件环境，本页讲清上限与要求。

## 上限与推荐

| 参数 | 数值 | 说明 |
| -- | ---- | ---- |
| 软件上限 | 8 台 | XBurn 软件支持的同时烧录设备上限，超过无法接入。 |
| 推荐并发 | ≤4 台 | 兼顾效率与失败概率的推荐数量，**非稳定性保证**。 |

:::warning 硬件原因导致的失败不在支持范围
多台并发对线材、hub、供电有要求，因这些硬件原因导致的烧录失败不在软件支持范围。
:::

## 操作建议

- **优先用主板原生 USB 口**，避免劣质 USB hub。
- **独立供电**：多设备并发时确保每台设备供电充足，避免单口供电不足。
- **高质量数据线**：每条 Type-C 数据线均需带屏蔽层、长度尽量短、支持数据传输（见各产品烧录文档的数据线要求）。
- **分批烧录**：设备数超过 4 台时，分批进行，每批 ≤4 台。

:::info 批量场景的自动重启
批量烧录时建议关闭 [烧录完成自动重启](./auto-reboot)，避免单台完成重启时影响其他设备烧录。
:::
