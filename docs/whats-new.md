# 最新动态

## V1.2.1（2026-06-01）

**新增功能**

- OHP 烧录。但 OHP 不适用于 RDK 生态用户，本手册不涉及 OHP 烧录用法。

## V1.2.0（2026-04-09）

**新增功能**

- RDK X5 烧录，包含全镜像烧录、指定区域烧录和批量烧录。

## V1.1.10（2026-03-23）

**新增功能**

- 批量烧录（RDK S100 / RDK S600）。
- 指定分区镜像烧录（RDK S100 / RDK S600）。

## V1.1.9（2026-02-02）

首次替代 D-Navigation，成为 RDK 系列推荐的烧录工具。自 RDK S100 V4.0.5、RDK S600 V5.1.0 固件起，官方推荐改用 XBurn。

**新增功能**

- 指定区域烧录（RDK S100 / RDK S600）。
- 指定区域备份（RDK S100 / RDK S600）。
- 批量烧录（X5 芯片）。
